# snowsurfmaster 投标演示脚本

## 演示前准备

### 1. 环境检查（演示前 5 分钟）

```bash
# 1. 激活虚拟环境
cd snowsurfmaster
source venv/bin/activate

# 2. 检查依赖
pip list | grep -E "mediapipe|streamlit|transformers"

# 3. 测试运行
streamlit run web/app.py --server.headless=true
```

### 2. 预设数据准备

确保以下文件存在：

```
snowsurfmaster/
├── data/
│   ├── demo/
│   │   ├── demo_beginner.mp4    # 初学者视频
│   │   ├── demo_intermediate.mp4 # 中级视频
│   │   └── demo_pro.mp4          # 专业视频
│   └── templates/
│       ├── parallel_turn_pro.json      # 专业模板
│       └── parallel_turn_beginner.json # 初学者模板
└── output/
    └── demo/
        ├── demo_beginner_report.html   # 预设报告
        └── demo_intermediate_report.html
```

## 演示流程（15 分钟）

### Part 1: 开场介绍（2 分钟）

**话术：**

> 这套系统可以帮助雪场：
> - 提升客户体验，让普通用户获得专业级动作指导
> - 增加二次消费，通过付费分析报告创造新收入
> - 打造差异化服务，在竞争激烈的雪场市场中脱颖而出"

**PPT 页：** 产品定位 + 核心价值

---

### Part 2: 实时演示（8 分钟）

#### Step 1: 系统界面展示（1 分钟）

**操作：** 打开浏览器，访问 `http://localhost:8501`

**话术：**
> "这是我们的 Web 分析界面，设计简洁直观，用户无需培训即可使用。"

**要点：**
- 界面简洁，用户体验友好
- 支持模板选择（专业/初学者）
- 支持大模型反馈开关

---

#### Step 2: 上传视频分析（3 分钟）

**操作：** 
1. 选择预设 Demo 视频（demo_intermediate.mp4）
2. 点击"开始分析"
3. 等待处理完成

**话术：**
> "现在我们上传一个中级滑雪爱好者的视频。系统会自动进行以下处理：
> 1. 提取视频中的骨骼关键点（MediaPipe）
> 2. 计算关节角度、对称性等指标
> 3. 与专业选手的标准动作对比（DTW 算法）
> 4. 生成自然语言反馈报告（Qwen-7B 大模型）
> 
> 整个过程大约需要 1-2 分钟，取决于视频长度。"

**要点：**
- 强调技术先进性（计算机视觉 + 大模型）
- 说明处理流程
- 管理预期（处理时间）

---

#### Step 3: 展示分析结果（3 分钟）

**操作：** 滚动查看分析结果

**话术：**
> "分析完成后，用户会看到：
> 
> **整体评分**：72 分，动作相似度良好
> 
> **详细指标**：
> - 左膝角度：良好（接近标准）
> - 身体前倾：需要改进（偏小 5 度）
> - 左右对称性：优秀
> 
> **专业反馈**：
> 系统会生成 300-500 字的详细报告，包括：
> - 总体评价
> - 做得好的地方
> - 需要改进的地方
> - 具体训练建议
> 
> 这些反馈不是模板化的，而是基于用户的实际动作数据生成的。"

**要点：**
- 量化指标直观易懂
- 反馈专业且可执行
- 强调个性化（非模板）

### Part 4: Q&A（2 分钟）

**预期问题：**

1. **Q: 准确率如何？**
   - A: MediaPipe 关键点检测准确率>95%，角度计算误差<5 度。我们建议将系统作为辅助工具，不替代专业教练。

2. **Q: 雪场网络不好怎么办？**
   - A: 系统支持完全离线运行，所有计算在本地完成。只需定期联网更新模型。

3. **Q: 能否分析其他运动？**
   - A: 当前专注滑雪，但技术框架可复用到冲浪、滑板等运动。这也是我们叫 snowsurfmaster 的原因。

4. **Q: 数据安全如何保障？**
   - A: 所有数据本地处理，不上传云端。用户视频分析完成后可选择删除。

## 演示注意事项

### 技术准备

1. **备用方案**：准备预先录制的演示视频，防止现场翻车
2. **网络**：确认演示环境网络稳定（如果需要联网）
3. **电源**：确保笔记本电脑电量充足
4. **投影**：提前测试投影仪分辨率（建议 1920x1080）

1. **不要读稿**：熟悉流程，自然表达
2. **与观众互动**：询问"大家滑雪时遇到过什么问题？"
3. **强调价值**：技术是手段，商业价值是目的
4. **控制时间**：严格 15 分钟，留 2 分钟 Q&A
