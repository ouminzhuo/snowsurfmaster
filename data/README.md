# 数据目录说明

## 📁 目录结构

```
data/
├── raw/           # 原始视频
├── processed/     # 处理后数据
├── templates/     # 标准动作模板
└── demo/          # 演示视频
```

## raw/ - 原始视频

放置待分析的滑雪视频文件

**要求**：
- 格式：MP4, MOV
- 时长：10-60 秒（建议）
- 分辨率：720p 以上
- 帧率：30fps 或 60fps

**拍摄建议**：
- 侧面或正面拍摄（避免背面）
- 光线充足，避免逆光
- 相机固定（使用三脚架）
- 包含完整动作过程

---

## processed/ - 处理数据

存储 MediaPipe 提取的骨骼数据和计算的运动指标

**文件命名**：
- `{video_name}_skeleton.json` - 骨骼关键点数据
- `{video_name}_metrics.json` - 关节角度等指标

---

## templates/ - 标准动作模板

存储专业选手的标准动作数据，用于对比分析

**当前模板**：
- `parallel_turn_pro.json` - 专业平行式转弯
- `parallel_turn_beginner.json` - 初学者平行式转弯

**模板来源**：
- 专业教练动作视频提取
- 公开教学视频标注
- 运动科学文献数据

---

## demo/ - 演示视频

预设的演示视频，用于投标展示和测试

**需要准备的视频**：
1. `demo_beginner.mp4` - 初学者典型错误动作
2. `demo_intermediate.mp4` - 中级爱好者标准动作
3. `demo_pro.mp4` - 专业选手完美动作

**视频来源建议**：
- 自己录制（推荐，无版权问题）
- YouTube 下载（注意版权，仅用于演示）
- 开源数据集

**推荐 YouTube 频道**：
- PSIA-AASI（美国滑雪教练协会）
- Ski Magazine
- Epic TV
- 各滑雪品牌官方频道

---

## ⚠️ 注意事项

1. **版权**：商用前确保视频有合法授权
2. **隐私**：避免使用包含他人面部清晰特征的视频
3. **质量**：视频质量直接影响分析精度
4. **存储**：视频文件较大，注意磁盘空间
